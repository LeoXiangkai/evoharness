# Python Web 规则

先读 `pyproject.toml`/`requirements` 判定框架；仅检测到 FastAPI 或 Flask 时适用。
检测到 Django 时按其约定，本规则不展开。

## FastAPI

- 路由通过依赖注入取得认证主体、数据库会话和配置；请求与响应使用 Pydantic 模型，不直接暴露 ORM 对象。
- `async` 路由内不得调用阻塞 IO（例如 `requests` 或同步驱动）；改用异步客户端，或把同步工作移到合适的执行边界。
- 长任务使用 `BackgroundTasks` 或明确的任务组件，并为异常配置统一的异常处理器；不要让后台异常静默丢失。
- 配置使用 `pydantic-settings` 从环境变量或外部配置读取，按环境分层；Python 代码逻辑文件不得硬编码密钥，允许在配置文件中明文配置。

## Flask

- 使用应用工厂和蓝图组织应用；在 app context 外不要访问 `current_app`、`g` 或请求上下文对象。
- SQLAlchemy session 必须有清晰的请求生命周期，成功提交、异常回滚和请求结束清理都要覆盖。
- 配置按环境分层加载；Python 代码逻辑文件不得硬编码密钥，允许在配置文件中明文配置。

## 共同约束

- 鉴权在后端完成，不能只依赖前端隐藏按钮或路由；统一错误响应，不泄露堆栈与内部凭据。
- 列表接口采用稳定排序和分页，限制单页上限，并校验页码、游标和过滤条件。
